# VLM 描述品質非正式對照

主力：`gemini-3.5-flash-lite`（`GEMINI_MODEL`）｜對照：`gpt-5-mini`（`OPENAI_MODEL`）。素材為 `events/` 的 12 張私人跌倒測試截圖；逐圖內容涉及居家隱私，只保留在本機。

## 可確認的結果

- 2026-07 的一次執行共送出 24 次呼叫（12 張 × 2 個 provider），兩邊都取得非 fallback 回應。
- 回應能產生繁體中文姿態與環境描述；格式與嚴重度分數在個別影像間有差異。
- 這份紀錄只能證明兩個 API 在這批私人影像上完成呼叫，不能證明醫療正確性、嚴重度校準或安全性。

## 方法限制

- 只有 12 張影像，而且來自同一個居家環境與測試者。
- 沒有獨立標註者、盲評、預先註冊 rubric 或統計檢定。
- 私人影像與逐圖輸出不公開，因此第三方無法完整重現內容評比。
- 對照模型不是裁判，也不是能排除系統性錯誤的安全備援；本次沒有做模型共識決策。

## 後續若要升級

需要建立可合法公開、涵蓋不同人物與場景的事件影像集，先定義姿態、環境、傷勢臆測與格式遵循 rubric，再由獨立標註者進行盲評並報告一致性。完成之前，這份文件只作為 API 整合紀錄。
